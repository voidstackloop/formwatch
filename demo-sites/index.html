formwatch demo site

A deliberately varied set of forms for seeing every check and edge case formwatch handles — one clean baseline, and pages that each trip a specific check or exercise a known platform limit. Start the server with formwatch demo, then browse, or run formwatch against them.

formwatch demo                       # serves this site on 127.0.0.1:8099
formwatch test http://127.0.0.1:8099/good-form.html
formwatch monitor demo-sites/forms.yml
formwatch report --html --out report.html
